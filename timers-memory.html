How it works:

The counter increments on each clock tick. When it reaches the target count (1000 ticks at 1kHz = 1 second), time is up!

counter = 0
while counter < target:
wait_for_tick()
counter++
// Time elapsed!

⏱️ Real-World Timer Applications

Timers are everywhere in computing. Your CPU's scheduler uses timers to switch between tasks. Network protocols use timers for timeouts. Even the blinking cursor is powered by a timer counter!

📦 Memory Addressing in Action

Memory is like numbered mailboxes: 0, 1, 2, 3... To read through memory sequentially, you need a counter that generates the next address. This is how DMA engines, graphics cards, and boot ROMs scan through data!
