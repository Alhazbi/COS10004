⚠️ Illegal States in Ripple Counters

Understanding why temporary unwanted values appear when flip-flops don't change simultaneously

💡 THE CORE IDEA

Illegal states are temporary, unwanted binary values that appear in a ripple counter because its flip-flops do NOT change at the same time.

⚡ Why Illegal States Are a Problem
🔍 Glitch Scenario: Detecting "101" for Reset
We want to detect:
101 (5)

To trigger Master Reset

⚠️
During 111→000 transition:
111 → 101 → 001 → 000

⚠️ Illegal state 101 triggers false reset!

The detection logic sees 101 momentarily and triggers a reset we didn't want!

📝 Summary

Illegal states are temporary, unintended binary values that appear because each flip-flop changes at different times (the ripple effect).

The counter never stops at these values — they exist only for nanoseconds. But connected logic circuits can see them and react incorrectly, causing glitches.

This is why synchronous counters (where all flip-flops change together) are preferred for precise timing applications.
