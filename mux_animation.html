🔧 Bits and Fixed Gates

Logic gates like AND, OR, NOT are fixed.
Once you build an AND gate, it will always compute A AND B.
It cannot choose to ignore an input or change its operation.

Click on A or B to change their values!

🤔 The "Choice" Problem

Sometimes, we don't want to combine A and B.
We want to choose:
"Use A now" or "Use B now".

How can a circuit decide which input to send to the output?

🚂 Train Track Analogy

Think of data like a train.
The control bit S is the lever that chooses the track:

S = 0 → go to A
S = 1 → go to B

We want a digital version of this switch.
(Click the lever to switch tracks!)

📦 The 2-to-1 MUX Block

Control S:
S = 0 → Y = I₀
This block is a multiplexer (MUX).
It selects one input and sends it to the output.

If S = 0 → Y = I₀
If S = 1 → Y = I₁

The control bit acts like a digital switch.

📊 Truth Table View

S Y
0 I₀
1 I₁
Toggle S:
We can summarize the MUX with a truth table.
For each value of S, exactly one row is active
and chooses one input.

🔌 Inside the MUX: Gate-Level

Toggle S:
S = 0 → Y = I₀
A 2-to-1 MUX is built from:
1 NOT gate, 2 AND gates, 1 OR gate

The control bit turns one AND gate on and the other off.
The OR gate passes through whichever path is on.

Watch how the Boolean expression builds up:
NOT: ¬S → AND: (¬S·I₀) and (S·I₁) → OR: Y = (¬S·I₀)+(S·I₁)

💡 The "NOT on 0" Rule

When S = 0
Y = I₀
Use ¬S (NOT S)
When S = 1
Y = I₁
Use S (no NOT)
Y = (¬S · I₀) + (S · I₁)
Notice the pattern:

For S = 0, we use ¬S (NOT S).
For S = 1, we use S itself.

Rule: If a control bit is 0 for that case → use its NOT.
If it is 1 → use it as is.

S₁S₀ = 00 → Y = I₀
A 4-to-1 MUX selects from 4 inputs using 2 control bits.
Built from: 2 NOT gates, 4 three-input AND gates, 1 four-input OR gate

Watch the Boolean expression build through each gate:
NOT: ¬S₁, ¬S₀ → AND: (¬S₁·¬S₀·I₀), (¬S₁·S₀·I₁), (S₁·¬S₀·I₂), (S₁·S₀·I₃)
→ OR: Y = sum of all active AND outputs

Each combination of S₁S₀ activates exactly one AND gate!
