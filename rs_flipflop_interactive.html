How RS Flip-Flop Works

Basic Principle:

An RS Flip-Flop is a fundamental memory circuit that stores 1 bit of information. It has two inputs (S and R) and two complementary outputs (Q and Q').

Operating Modes:

  • Set (S=1, R=0): Forces Q to 1 and Q' to 0, regardless of previous state.
  • Reset (S=0, R=1): Forces Q to 0 and Q' to 1, regardless of previous state.
  • Hold/Memory (S=0, R=0): Maintains the current state - this is the memory function!
  • Invalid (S=1, R=1): Forbidden state that creates undefined behavior.

Key Features:

  • Stores one bit of data (0 or 1)
  • Retains state even when inputs are removed (memory)
  • Q and Q' are always complementary (opposite values)
  • Built using cross-coupled NOR or NAND gates

Applications:

  • Building blocks for other flip-flops (D, JK, T)
  • Switch debouncing circuits
  • Control circuits and state machines
  • Temporary data storage
