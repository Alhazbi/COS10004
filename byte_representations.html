💡 Key Concepts:

🔷 Same Byte, Different Meanings: The exact same 8 bits can represent a number, a letter, a color, or pixels - it all depends on how we interpret it!

🔷 1 Byte = 8 Bits: With 8 bits, we can represent 256 different values (2^8 = 256), numbered from 0 to 255

🔷 ASCII: A standard that assigns numbers to characters. For example, 'A' = 65, 'B' = 66, 'a' = 97, 'b' = 98

🔷 Grayscale: In black & white images, each pixel's brightness is stored as a byte: 0 = pure black, 255 = pure white, values in between = shades of gray

🔷 Context Matters: The computer doesn't know if a byte represents a letter or a number - that's determined by the program using it!
