💡 Understanding the Ripple

1. Clock Toggles Q₀

Each clock pulse makes Q₀ toggle. If standing (1), it falls (0). If fallen (0), it rises (1).

2. Falling Triggers Next

Only when a domino FALLS (1→0) does it trigger the next one. Rising (0→1) does nothing!

3. The Ripple Delay

Each trigger takes time to propagate. This delay is why it's called a "ripple" counter.
