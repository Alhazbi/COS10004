2-to-1 Multiplexer (MUX)

Built from Basic Logic Gates

Boolean Algebra Expression

Y = S̄ · I₀ + S · I₁
(NOT S AND I₀) OR (S AND I₁)
Where:
• S = Select input
• S̄ = NOT S (inverted select)
• I₀, I₁ = Data inputs
• Y = Output
• · = AND operation
• + = OR operation

How it works: When S=0, the NOT gate outputs 1, enabling the top AND gate to pass I₀. The bottom AND gets 0 from S, blocking I₁. When S=1, the NOT gate outputs 0, blocking I₀ in the top AND. The bottom AND gets 1 from S, passing I₁. The OR gate combines both paths.
