2-to-1 Multiplexer (MUX)

Built from Basic Logic Gates

Boolean Algebra Expression

Y = S̄ · I₀ + S · I₁
(NOT S AND I₀) OR (S AND I₁)
Where:
• S = Select input
• S̄ = NOT S (inverted select)
• I₀, I₁ = Data inputs
• Y = Output
• · = AND operation
• + = OR operation

How it works: When S=0, the top AND gate is enabled (via NOT gate) and outputs I₀. When S=1, the bottom AND gate is enabled and outputs I₁. The OR gate passes whichever AND gate is active.
