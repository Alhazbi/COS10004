📖 How NOR RS Flip-Flop Works

A NOR-based RS flip-flop uses two NOR gates connected in a feedback loop. Each gate's output feeds back to the other gate's input, creating a bistable circuit that can store one bit of information.

⚠️ Key Difference from NAND: Unlike NAND-based RS latches which use active-low inputs (0 to activate), NOR-based RS latches use active-high inputs (1 to activate). The forbidden state is also reversed (S=1, R=1 for NOR vs S=0, R=0 for NAND).
  • SET (S=1, R=0): The 1 on S forces Gate B to output 0 (Q̅=0), which feeds back to Gate A making Q=1
  • RESET (S=0, R=1): The 1 on R forces Gate A to output 0 (Q=0), which feeds back to Gate B making Q̅=1
  • HOLD (S=0, R=0): Both inputs low - the feedback loops maintain whatever state was previously set
  • NOR Logic: Output is 1 only when BOTH inputs are 0; any input being 1 forces output to 0
