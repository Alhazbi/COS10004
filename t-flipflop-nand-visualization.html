⚡ T Flip-Flop with NAND Gates

All-NAND implementation (same as JK with J=K=T)

🎯 Key Concept

The T (Toggle) Flip-Flop has only ONE control input. When T=1 and clock pulses, the output toggles. When T=0, the output holds.


Circuit Structure (from lecture slide 11): 4 NAND gates total:

• Two 3-input NAND gates for input gating (with T, CLK, and feedback)

• Two 2-input NAND gates forming the cross-coupled SR latch


The Magic: NAND gates output 0 only when ALL inputs are 1. The feedback from Q and Q' ensures only ONE input NAND can output 0 at a time!

📖 How It Works

All-NAND T Flip-Flop (Lecture Slide 11 Design)

This circuit uses 4 NAND gates - identical to JK flip-flop but with J=K=T:


• T=0 (HOLD): Both 3-input NANDs output 1 (since T=0 makes it impossible for all inputs to be 1). S̄=R̄=1 tells the NAND latch to hold.


• T=1 (TOGGLE): Feedback determines which NAND can output 0:

   - If Q=0 (Q'=1): NAND1 sees all 1s → S̄=0 → SET Q to 1

   - If Q=1 (Q'=0): NAND2 sees all 1s → R̄=0 → RESET Q to 0


NAND SR Latch Rules: S̄=0 sets Q=1, R̄=0 resets Q=0, S̄=R̄=1 holds state
