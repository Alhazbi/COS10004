How a 2-to-1 Multiplexer Works

A multiplexer (MUX) is a digital switch that selects one of several input signals and forwards it to a single output line. A 2-to-1 multiplexer has:

  • Two data inputs: I0 and I1
  • One selector input: S (also called the control bit)
  • One output: Y

The selector bit S determines which input is routed to the output:

  • When S = 0, the output Y equals I0
  • When S = 1, the output Y equals I1
