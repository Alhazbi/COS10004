⚠️ Problem #2 - Too Many Inputs!
Think about it... we're trying to store ONE bit of information (either 0 or 1).

But we need to control TWO inputs (S and R) to do it!

That's like needing two steering wheels to drive one car! 🚗🚗
Visualizing the Inefficiency
The Inefficiency: We want to store just 1 bit, but we need to manage 2 inputs!

Plus, we need to be careful to never set both to 0 (or we get the forbidden state).

Wouldn't it be nice if we only needed ONE input? 🤔

🎯 Key Problem #2

Using two inputs (S and R) to store one bit is wasteful and complicated. We need a simpler way!
