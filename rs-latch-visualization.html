📖 How RS Flip-Flop Works

An RS flip-flop uses two NAND gates connected in a feedback loop. Each gate's output feeds back to the other gate's input, creating a bistable circuit that can store one bit of information.

🔑 Key Concepts:

  • SET (S=0, R=1): The 0 on S forces the upper NAND to output 1 (Q=1), which then feeds back to make Q̅=0
  • RESET (S=1, R=0): The 0 on R forces the lower NAND to output 1 (Q̅=1), which then feeds back to make Q=0
  • HOLD (S=1, R=1): Both inputs high - the feedback loops maintain whatever state was previously set
  • Each NAND gate has 2 inputs: One from S or R, and one from the feedback loop
