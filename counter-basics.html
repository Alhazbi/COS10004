🔧 How It Works

Each flip-flop stores one bit. When a clock pulse arrives, the counter increments by 1. The rightmost bit (2⁰) toggles on every pulse. When it changes from 1→0, it triggers the next bit to toggle, creating a ripple effect that produces the binary counting sequence.
