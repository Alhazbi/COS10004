💡 How It Works:

🔷 Each Row = 1 Byte: Every row of 8 pixels is stored as one byte (8 bits)

🔷 Black Pixel = 1, White Pixel = 0: When a pixel is black, its bit is 1. When it's white, its bit is 0

🔷 Reading Left to Right: The leftmost pixel is the most significant bit (128), rightmost is least significant (1)

🔷 This is Real Image Storage! Simple black & white images (like old computer graphics and icons) are stored exactly like this

🔷 8×8 Image = 8 Bytes: Our entire 64-pixel image takes only 8 bytes of memory!

🔷 Example: If all pixels in a row are black: 11111111 in binary = 255 in decimal = 0xFF in hex
